# Data Sources

## data/corpus/

The files in `data/corpus/` are unmodified PDFs of six tutorials and lecture-style
notes on machine learning and software engineering for machine learning, downloaded
from arXiv. Each one is licensed under the Creative Commons Attribution 4.0
International license (CC BY 4.0, https://creativecommons.org/licenses/by/4.0/),
as stated on its arXiv abstract page for the version listed below.

The only change is the file name: each file was renamed to a short topic slug
followed by its arXiv identifier and version. The contents are byte-for-byte the
files served by arXiv. The SHA-256 checksums below identify the exact files.

No endorsement by the authors is implied.
